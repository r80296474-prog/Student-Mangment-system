Student Management System
Project Overview
Student Management System is a web-based application developed to manage student information in a centralized and organized manner. The system helps educational institutions reduce manual work, maintain student records, and easily access important student information.
The project is developed using Python Flask as the backend framework and MySQL as the database management system.
